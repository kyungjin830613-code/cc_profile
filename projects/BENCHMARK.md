# 경쟁 앱 벤치마킹 (2026-11-24)

조사 방법과 한계
- 토스 미니앱은 토스 앱 안에서만 보이고, 클라우드에서는 toss.im 접속이 막혀 있어 **토스 안의 경쟁 미니앱은 직접 못 봤다.**
- 대신 같은 기능의 **앱스토어 인기·대표 앱**의 공식 소개(기능·디자인 설명)를 비교했다. 로고 그림은 직접 보지 못해서, 시각 비교는 소개 문구와 토스 공식 로고 규정 기준이다.
- 토스 안 경쟁 미니앱은 사용자가 토스 앱에서 검색해 캡처를 보내 주면 보강한다.

## 1. 토스 로고 규정 점검 (공식 미니앱 브랜딩 가이드)

| 규정 | 우리 로고 13개 |
|---|---|
| 600×600 PNG, **각진 정사각형**(둥근 모서리 금지) | ✅ 전부 꽉 찬 정사각형 PNG |
| **투명 배경 금지**, 라이트·다크 모드에서 잘 보이는 배경색 | ✅ 전부 불투명 배경. 신년운세(빨강)·N빵(보라)·공과금(남색)은 다크 모드에서도 대비 충분 |
| 토스 제공 아이콘·이미지(파생 포함) 사용 금지 | ✅ 전부 직접 그린 그림. 돈 습관 결산 로고만 Noto 이모지(오픈 라이선스) 사용 |
| 화면에서 아이콘·이모지 2개 이상 나란히 조합 지양(UI 가이드) | ⚠️ 일부 화면 버튼·목록에 이모지를 많이 씀 → 검수 지적 시 줄이기 |

| 물 한 잔 습관, 무지출 도장판, 점심 룰렛, 공과금, 평수, 소원 등불 | 앱스토어 비교 자료 부족 | — | 기본 기능 완성 | 토스 앱 안 경쟁 미니앱 캡처를 받아 보강 |

## 3. 그래픽 스타일 비교

- **경쟁 앱(앱스토어)**: 디데이 앱은 꾸미기(스티커·배경·글꼴)와 위젯이 핵심, 타이머는 Forest처럼 귀여운 캐릭터·게임화가 강세, 정산·장부 앱은 깔끔한 목록·차트형.
- **토스 미니앱**: 토스 디자인 시스템을 쓰는 흰 바탕·단정한 카드형이 많다(조사 자료 기준).
- **우리 앱**: 앱마다 고유 색과 직접 그린 단순한 그림 로고(봉투·등불·떡·컵 등). 특정 앱을 따라 그리지 않았고, 토스 규정(정사각형·불투명)을 지킨다. 화면은 흰 카드형으로 토스 안에서 이질감이 적다.
- **차이·보완점**: 경쟁 앱 대비 **꾸미기·캐릭터 성장 같은 '재미 요소'가 약함** → 디데이 카드 테마, 타이머 토마토 성장 등을 다음 업데이트로.

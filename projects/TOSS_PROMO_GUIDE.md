# 토스 미니앱 홍보 지침

사용자가 "○○ 앱 홍보해", "홍보 키트 만들어" 같이 지시하면 리야가 이 지침대로 준비하고, PC에서 올린다.

## 1. 원칙

- 토스는 **재방문·실사용**이 많은 앱을 더 노출한다. 홍보의 목표는 "한 번 설치"가 아니라 "다시 오게" 하는 것이다.
- 먼저 매일 쓰는 습관형 앱을 민다: 물 한 잔 습관, 무지출 도장판, 집중 타이머, 새해 소원 등불.
- 앱 안의 공유 문구·결과 카드는 무료 홍보 수단이다. 홍보할 때 공유 문구와 카드도 함께 다듬는다.
- 돈이 드는 홍보(토스 광고, 포인트 지급 등)는 재방문이 확인된 앱에만, 사용자 승인 후에 한다.

## 2. 시기 달력

| 시기 | 밀 앱 |
|---|---|
| 11월 말~1월 | 찰떡 신년운세, 새해 소원 등불, 나의 돈 습관 결산 |
| 명절·결혼 시즌(봄·가을) | 경조사비 장부 |
| 겨울 난방철·여름 냉방철 | 우리집 공과금 계산 |
| 연말 모임·회식철 | N빵 정산기, 오늘 점심 룰렛 |
| 새학기·시험기간 | 집중 타이머 |
| 이사철 | 평수 계산기 |
| 상시 | 디데이 모아보기, 물 한 잔 습관, 무지출 도장판, 찰떡 지갑궁합 |

## 3. 채널별 방식

| 채널 | 형식 | 요령 |
|---|---|---|
| 유튜브 쇼츠 | 15~30초 화면 녹화 + 자막 | 첫 2초에 문제 상황("회식비 누가 얼마?"), 끝에 "토스에서 ○○ 검색". 일상비화 쇼츠 끝에 한 줄 소개도 가능 |
| 인스타그램 | 릴스 또는 결과 카드 이미지 | 저장·공유하고 싶은 결과 카드 중심 |
| 스레드 | 짧은 공감 글 + 앱 링크 | 질문형 첫 줄("경조사비 얼마 냈는지 기억 안 나는 사람?") |
| 블로그 | 검색용 사용법 글 | 검색어 제목("전기요금 계산 방법 2026"), 사용 순서 캡처, 계산 근거 출처 |

## 4. 홍보 키트 (앱마다 만들 것)

1. 쇼츠 대본 1개 (장면·자막·내레이션)
2. 인스타 카드 이미지 3장 또는 릴스 대본
3. 스레드 글 2~3개
4. 블로그 초안 1개
5. 앱 링크와 검색어("토스에서 ○○ 검색")

키트는 `projects/<앱 폴더>/promo/`에 저장한다.

## 5. 지킬 것

- 토스 로고나 "토스 공식" 같은 표현은 쓰지 않는다. "토스 미니앱 ○○"라고 쓴다.
- 운세·돈 관련 앱은 "재미로 보는", "참고용" 문구를 붙인다. 투자·금융 조언처럼 쓰지 않는다.
- 사실(요금표·세율 등)은 출처 2곳 이상을 확인한다.
- 캡처에 개인정보가 보이지 않게 한다. 영상 속 실존 인물 얼굴 생성 금지.
- 사용자의 이메일·개인정보는 외부 서비스에 보내지 않는다.

## 6. 올리는 방법

- 유튜브: 사용자 상시 승인 범위 → PC에서 업로드·공개까지 진행하고 링크를 보고한다.
- 인스타그램·스레드·블로그: 계정 로그인은 사용자가 처음 한 번 직접 한다. 로그인된 뒤에는 사용자 지시에 따라 PC에서 게시한다.
- 게시 후 보고: 채널 / 앱 / 링크 / 48시간 뒤 반응(조회·좋아요·댓글).

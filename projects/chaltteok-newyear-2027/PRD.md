# 찰떡 신년운세 2027 기획서 v0.1

> 찰떡 시리즈 2탄. 2027년 정미년(붉은 양의 해) 신년운세 토스 미니앱.
> 작성: 리야 · 2026-11-22 · 상태: 초안 (사용자 검토 전)

## 1. 한 줄 요약
생일만 넣으면 **"나의 2027년 한 단어"**와 **12달 운세 달력**이 귀여운 붉은 양 캐릭터 카드로 나온다.

## 2. 왜 지금인가
| 근거 | 내용 |
|---|---|
| 최대 성수기 | 신년운세 검색·이용은 12월~설날에 몰린다. 2027년 설날은 **2월 6일**, 입춘은 **2월 4일** |
| 해의 이름이 화제 | 2027년은 **정미년(丁未), 붉은 양의 해**. "붉은 양", "2027 삼재" 같은 검색어가 연말에 뜬다 |
| 1탄 자산 재사용 | 찰떡 지갑궁합의 사주 엔진(43,464일 검증), 캐릭터, 병맛 톤, 토스 연동 코드를 그대로 쓴다 |

## 3. 일정 리스크와 대응
- 토스 미니앱 출시는 게임이 아닌 앱 기준 **1~3개월**이 걸린다고 안내돼 있다. **12월 초 심사 제출**이 목표.
- 늦어질 경우를 대비해 **웹 버전을 먼저** 띄워 인스타·스레드 홍보에 쓰고, 토스 출시 후 링크를 바꾼다.
- 입춘(2/4)·설날(2/6) 직전까지가 2차 성수기라, 1월 출시여도 의미가 있다.

## 4. 사주 근거 (계산은 정확하게, 해석은 재미로)
- **올해의 기운:** 2027년 세운은 丁未. 천간 丁(음의 불), 지지 未(양, 흙).
- **나의 2027 한 단어:** 내 일간(태어난 날의 천간)과 丁의 관계(십신)로 10가지 테마를 정한다.

| 십신 | 테마 이름(안) | 키워드 |
|---|---|---|
| 비견 | 든든한 동료의 해 | 협업, 친구 |
| 겁재 | 승부욕 불타는 해 | 경쟁, 도전 |
| 식신 | 먹복·재주 터지는 해 | 즐거움, 취미가 돈 |
| 상관 | 말발·변신의 해 | 표현, 이직·변화 |
| 편재 | 뜻밖의 보너스 해 | 부수입, 기회 |
| 정재 | 알뜰 수확의 해 | 월급, 저축 |
| 편관 | 압박 속 성장의 해 | 책임, 체력 관리 |
| 정관 | 인정받는 해 | 승진, 신뢰 |
| 편인 | 번뜩이는 아이디어의 해 | 기획, 공부 |
| 정인 | 귀인 만나는 해 | 도움, 자격증 |

- **띠와 未의 관계:** 午(말)는 육합, 亥·卯(돼지·토끼)는 삼합, 丑(소)은 충, 子(쥐)는 해(害), 未(양)는 내 띠의 해.
- **2027 삼재:** 亥卯未 띠(돼지·토끼·양)가 **나가는 삼재(날삼재)**. 겁주지 않고 "마무리의 해"로 가볍게 안내한다.
- **12달 달력:** 2027년 각 달의 월주(2월 壬寅 ~ 2028년 1월 癸丑)와 내 일간·일지의 관계로 달마다 ★1~5와 한 줄 조언. 달의 시작은 절기 기준(2/4 입춘, 3/6 경칩 …).

## 5. 기능 (v1, 사업자 없이 무료)
1. 별명·양력 생일 입력, 19세 이상 확인 (지갑궁합에서 저장한 정보가 있으면 불러오기)
2. **나의 2027 한 단어 카드**: 붉은 양 캐릭터 + 테마 이름 + 세 줄 풀이
3. **분야별 별점**: 돈·연애·일·사람 (십신 성격으로 가중치)
4. **12달 운세 달력**: 가장 좋은 달 / 조심할 달 강조
5. **띠별 한마디 + 삼재 여부**
6. 공유: 결과 문구, 카드 이미지 저장
7. 다른 앱 연결: "애인과 지갑궁합도 보기" 버튼 (찰떡 지갑궁합으로 이동)

## 6. 다음 버전 (사업자 등록 후)
- 광고(배너·전면), **990원 상세 리포트**(월별 상세 풀이, 좋은 날짜)
- 월초 알림: "이번 달 운세가 도착했어요" (동의자만)

## 7. 콘텐츠 재활용 (마케팅)
- 띠별 12개 카드뉴스 → 인스타·스레드 (지숙이와 역할 분담 필요)
- 일상비화 채널 쇼츠: "붉은 양의 해, 원래 무슨 뜻일까?" 같은 소재

## 8. 정책·고지
- "재미로 보는 운세이며 의학·금융·법률 조언이 아닙니다"
- 건강 관련 단정(병, 사고) 금지. 삼재는 공포 마케팅 금지
- 개인정보: 기기 안에서만 계산, 서버 저장 없음

## 9. 기술
- 찰떡 지갑궁합 코드 구조 재사용 (Vite + React + `@apps-in-toss/web-framework`)
- 십신·월주 계산 추가, 2027 월주표와 절기 날짜는 만세력 라이브러리로 검증하는 테스트 포함
- 장기적으로 두 앱의 공통 엔진을 `packages/saju` 같은 공용 모듈로 분리

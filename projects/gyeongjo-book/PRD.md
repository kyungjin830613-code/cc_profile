# 경조사비 장부 기획서 (PRD)

- appName: `gyeongjo-ledger`(gyeongjo-book은 다른 사람이 이미 사용) / 앱 유형: 비게임
- 앱 이름(10자 이내): 경조사비 장부 (7자)
- 폴더: `projects/gyeongjo-book/app`, 로고: `assets/logo-1024.png`, `assets/logo-600.png`
- 작성: 리야, 2026-11-23

## 1. 왜 만드나

- 원래 후보는 "세뱃돈 계산기"였지만 설날 전 2~3주만 쓰이고 재방문이 없어 버렸다(사용자 결정).
- 축의금·조의금 안내 글들이 공통으로 말하는 **가장 확실한 기준은 "상대가 나에게 냈던 금액"**. 그걸 기억하게 해 주는 장부가 핵심.
- 결혼식·장례식·돌잔치는 1년 내내 있고, 기록이 쌓일수록 계속 쓰게 된다 → 토스 노출 기준(재방문)에 맞다.

한 줄 소개: "그 사람이 우리 결혼식에 얼마 냈더라? 받은 돈·낸 돈을 기록하고, 얼마 낼지 추천받아요."

## 2. 기능(구현 완료)

| 기능 | 내용 |
|---|---|
| 얼마 낼까 | 이름 입력 → 장부에 받은 기록이 있으면 **받은 만큼** 추천(같은 종류 경조사 우선). 없으면 경조사 종류·관계·참석/식사·호텔·동행 인원으로 추천 금액과 보통 범위, 이유를 보여 줌 |
| 장부 | 받았어요/냈어요, 이름, 금액(만원), 경조사, 관계, 날짜, 메모. 눌러서 고치기·지우기 |
| 사람별 | 사람마다 받은 돈·낸 돈·차이("갚을 마음 ○만원" / "딱 맞음"), 펼치면 내역 |
| 올해 합계 | 올해 낸 돈, 받은 돈, 기록한 사람 수 |
| 바로 기록 | 추천 화면에서 "이 금액으로 냈어요" → 장부에 바로 저장 |
| 공유 | "○○님 결혼식 얼마 낼까 → 10만원" + 앱 링크 |

## 3. 추천 기준(참고값, 화면에 그렇게 표시)

여러 2026년 안내 글의 공통 범위(만원):

| 관계 | 축의금 | 조의금 |
|---|---|---|
| 가족·친척 | 10~30 | 10~30 |
| 아주 친한 친구 | 10~20 | 10~20 |
| 친구 | 5~10 | 5~10 |
| 같은 팀·친한 동료 | 5~10 | 5~10 |
| 직장 동료 | 5 | 3~5 |
| 지인 | 3~5 | 3~5 |

- 결혼식에 가서 식사하면 범위 가운데 이상, 안 가면 낮은 쪽. 호텔이면 10만원 이상, 동행 1명당 5만원 추가.
- 돌잔치·기타는 공통 기준이 뚜렷하지 않아 결혼식 범위의 낮은 쪽을 참고하고, 기록을 권한다.
- 금액은 3·5·7·10만원, 그 위로는 5만원 단위.
- 출처: ourhour.co.kr 축의금 기준 2026, bal.pe.kr 축의금·조의금 정리 2026, chongmulab 계산기, glasswallet 조의금 기준표 2026, funeralhow 조의금 2026. 공식 통계가 아니므로 "참고값"으로만 표기.

## 4. 개인정보

- 장부(이름·금액)는 **기기 안(토스 Storage)에만** 저장. 서버 전송 없음.
- 기기를 바꾸면 기록이 옮겨지지 않는다 → 다음 버전에서 "내보내기/가져오기(복사 붙여넣기)" 검토.

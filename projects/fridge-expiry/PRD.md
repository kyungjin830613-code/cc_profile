# 냉장고 유통기한 (appName `naengjanggo-yutong-gihan`)

## 한 줄 소개
냉장고에 넣은 식재료와 유통기한을 적어 두면, 임박한 순서로 보여 주고 오늘 먹을 것을 알려 주는 생활 기록 앱.

## 왜 다시 오나
- 장 볼 때(넣기), 요리할 때(오늘 먹을 것 확인), 다 먹었을 때(기록)마다 연다.
- 이번 달 '다 먹음/버림/알뜰률'이 쌓여 절약 습관이 된다.
- 기존 앱과 겹치지 않음: 무지출 도장판(돈 안 쓴 날)과 달리 음식 재고 관리.

## 기능
1. 식재료 넣기: 이름, 종류(9가지), 보관(냉장·냉동·실온), 유통기한(오늘/+3/+7/+14/+30일 빠른 선택 또는 날짜 직접). 자주 넣는 것 12개 빠른 입력
2. 오늘 먹을 것: 오늘·내일 마감 식재료를 맨 위 카드에
3. 목록: 지남 / 오늘·내일 / 3일 이내 / 여유 네 묶음, 남은 날 배지(D-n, 오늘까지, n일 지남), 보관 칸별 보기
4. 다 먹었어요 / 버렸어요 / 잘못 넣음 지우기
5. 이번 달 기록: 다 먹음·버림·알뜰률, 공유

## 정책·안전 문구
- 빠른 입력 날짜는 입력을 돕는 기본값일 뿐 식품 안전을 보장하지 않는다고 화면에 표시. 포장 날짜 우선.
- 의료·식품 안전 조언처럼 쓰지 않는다.

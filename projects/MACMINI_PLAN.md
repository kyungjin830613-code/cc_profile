# 맥미니 M2(16GB·512GB) + 스마트 TV 연결·활용 기획안

작성: 리야, 2026-11-27. 사용자 원문: "맥미니 M2 16기가의 512 이거를 내 그 스마트 TV에 연결을 하려고 해. 연결할 수 있는, 바로 연결해서 쓸 수 있는 케이블하고, 그리고 어떻게 써야지 맥미니를 효율적으로 쓸 수 있는지 기획안을 나한테 보고해줘. 그리고 맥미니 사용법, 어떻게 하면은 맥미니를 잘 쓰는지 그런 것도 같이"

## 1. 연결 준비물

| 준비물 | 추천 | 이유 |
|---|---|---|
| **HDMI 케이블** (필수) | **HDMI 2.1 "울트라 하이스피드"** 또는 HDMI 2.0 "프리미엄 하이스피드" 인증, 2~3m | 맥미니 M2 뒷면에 HDMI 단자가 있어 **HDMI ↔ HDMI 케이블 한 줄**이면 끝. 4K 60Hz까지 나옴 |
| **무선 키보드·마우스** (필수) | 블루투스 키보드+마우스(또는 트랙패드). 소파에서 쓰면 **터치패드 일체형 무선 키보드**가 편함 | 맥미니엔 키보드·마우스가 없음 |
| 유선 USB 키보드/마우스 (있으면) | 아무거나 | **첫 설정 때** 블루투스 연결 전까지 쓰기 쉬움 |
| 외장 SSD (권장) | USB-C(썬더볼트) 1TB 이상 | 512GB는 영상 작업하면 금방 참 → 영상·자료는 외장으로 |
| 랜선 (권장) | 공유기와 유선 연결 | 원격 작업·업로드가 안정적 |

- 맥미니 M2 뒷면: HDMI 1, 썬더볼트4(USB-C) 2, USB-A 2, 이더넷 1, 헤드폰 1.
- 모니터를 하나 더 쓰고 싶으면 **USB-C → HDMI 케이블**로 두 번째 화면도 가능.
- 소리는 HDMI로 **TV 스피커**에서 나옴.

## 2. 연결 순서 (10분)

1. 맥미니 HDMI ↔ TV HDMI 꽂기(TV 쪽은 가능하면 **"HDMI 2"·"PC"·"게임" 표시가 있는 단자**).
2. 유선 키보드·마우스 꽂기(없으면 블루투스 기기를 페어링 모드로).
3. 맥미니 전원 켜기 → TV 입력을 그 HDMI로.
4. 처음 설정: 언어·Wi-Fi·**Apple ID 로그인(사용자 직접)**.
5. TV 화질 설정(글자가 또렷해짐):
   - 그 HDMI 입력의 **기기 유형/아이콘을 "PC"**로 바꾸기
   - 삼성: **입력 신호 플러스** 켜기 / LG: **HDMI ULTRA HD Deep Colour** 켜기
   - 화면 모드 **게임 모드** 또는 **PC 모드**(입력 지연·흐림 줄어듦)
6. 맥 설정: **시스템 설정 → 디스플레이**
   - 해상도 **"더 큰 텍스트"** 쪽으로(소파 거리에서 글씨 크게)
   - 화면 테두리가 잘리면 **"언더스캔"** 슬라이더 조절
   - 새로고침 빈도 60Hz

## 3. 맥미니를 이렇게 쓰자 (효율 기획)

**핵심: 맥미니를 "반짝이 전용 작업 PC"로.** 지금 윈도우 PC는 지숙이·Pixeling이 같이 써서 C 드라이브가 차고 크롬 연결(Playwriter)이 자꾸 끊겼다. 역할을 나누면 둘 다 안정적이다.

| 기기 | 역할 |
|---|---|
| 윈도우 PC | 지숙이(Codex)·Pixeling 전용 |
| **맥미니** | **반짝이(Claude Code) 원격 작업 PC**: 일상비화 영상 제작·업로드, 스레드·크몽·토스 콘솔 브라우저 작업, 전자책·미니앱 빌드 |
| 스마트 TV | 맥미니 큰 화면 + 영상 결과 확인(쇼츠·유튜브를 큰 화면으로 검수) |

장점
- 브라우저 작업이 지숙이와 **안 겹쳐서** 연결이 덜 끊김
- M2는 **영상 편집·렌더링이 빠르고 조용함**, 전기도 적게 먹음(24시간 켜 두기 좋음)
- 휴대폰 → 리야 → 맥미니로 지금 방식 그대로 원격 운영

세팅 할 일(맥미니 연결 후 리야가 단계별 안내)
1. **잠자기 끄기**: 시스템 설정 → 에너지 → "디스플레이가 꺼져 있을 때 자동으로 잠자기 방지" 켜기, "정전 후 자동 시동" 켜기
2. **자동 로그인**은 보안상 선택(사용자 결정)
3. Claude Code 설치 → `claude remote-control`로 **두 번째 작업 PC**로 연결(새 환경 등록)
4. 크롬 + Playwriter 확장 설치, 유튜브·스레드·토스 콘솔 **로그인(사용자 직접)**
5. 외장 SSD를 작업 폴더로(영상·이미지 결과물 저장)
6. **화면 공유** 켜기: 다른 기기에서 맥 화면 보기
7. 일상비화 제작 도구(ffmpeg 등) 설치 → 리야가 체크리스트로

주의: 지숙이·Pixeling 자료는 옮기지 않는다(윈도우에 그대로). 로그인·결제는 사용자 직접.

## 4. 맥 처음 쓰는 사람을 위한 사용법

**윈도우와 다른 점 5가지**
1. **Ctrl 대신 ⌘(Command)**: 복사 ⌘C, 붙여넣기 ⌘V, 저장 ⌘S, 창 닫기 ⌘W, 앱 끄기 ⌘Q
2. **Dock**(화면 아래 줄) = 작업표시줄, **Finder** = 파일 탐색기
3. 창 왼쪽 위 빨강●(닫기)·노랑●(내리기)·초록●(전체 화면)
4. 앱 설치: **App Store** 또는 받은 파일을 "응용 프로그램" 폴더로 끌어다 놓기
5. 프로그램은 빨간 버튼으로 닫아도 켜져 있을 수 있음 → **⌘Q**로 완전히 끄기

**꼭 외울 단축키**
| 단축키 | 기능 |
|---|---|
| ⌘ + Space | Spotlight(앱·파일 검색) — 제일 많이 씀 |
| ⌘ + Tab | 앱 전환 |
| ⌘ + Shift + 4 | 영역 캡처(⌘+Shift+5는 화면 녹화) |
| ⌃(Control) + ⌘ + Q | 화면 잠금 |
| ⌘ + , | 지금 앱의 설정 |
| ⌥(Option) + ⌘ + Esc | 응답 없는 앱 강제 종료 |

**잘 쓰는 팁**
- 트랙패드/마우스 제스처: 시스템 설정 → 트랙패드에서 세 손가락 쓸기(데스크톱 전환) 켜기
- **Stage Manager**(제어 센터)로 TV 큰 화면에서 창 정리
- 아이폰이 있으면 **AirDrop**으로 사진·영상 바로 옮기기, **연속성 카메라**로 아이폰을 웹캠처럼
- 저장공간: 시스템 설정 → 일반 → 저장 공간에서 큰 파일 정리, 영상은 외장 SSD로
- 업데이트: 시스템 설정 → 일반 → 소프트웨어 업데이트(작업 없는 밤에)

## 4-1. 리야·지숙이 함께 쓰기 (2026-11-28 회의안)

사용자 원문: "맥미니를 집에다 두고 이제 밖에 외부에서도 맥미니 리아하고 지숙이한테 지침을 주면 알아서 자동화로 돌아가게 만들려고 하는 거야. … 이 노트북은 내가 상시 가지고 다니면서 어디서든지 업무할 수 있고 … 지숙이는 이제 뭐 블로그 전담, 뭐 그리고 블로그 자동화, 스레드 … 크롬에서 동시에 접속해서 쓰면 … 나누는 방법을 생각을 해보자."

**기기 역할**: 맥미니(집, 24시간) = 리야+지숙이 자동화 본부 / 윈도우 노트북 = 사용자 휴대용(Pixeling 포함) / 휴대폰 = 지시.

**핵심: 브라우저를 아예 따로 쓴다** (같은 크롬을 나눠 쓰면 끊김)

| | 리야(Claude) | 지숙이(GPT/Codex) |
|---|---|---|
| 브라우저 | **Google Chrome** + Playwriter | **다른 브라우저**(Chrome Beta 또는 Edge) — 별도 프로그램이라 로그인·확장·창이 안 섞임 |
| 작업 폴더 | `~/work` | `~/jisuk` (서로 안 건드림) |
| 담당 | 유튜브(일상비화·롱폼) 제작·업로드, 토스 콘솔·미니앱 빌드, 크몽·리틀리·전자책, 영상 렌더 | 블로그(글·자동화), 스레드 운영·자동 게시 |
| 넘겨받기 | `~/shared/넘김/`에 글 원고를 두면 상대가 가져가 게시 (예: 전자책 스레드 글은 리야가 쓰고 지숙이가 게시) | |

**자원 나누기 (M2 16GB)**
- 영상 렌더·대량 빌드는 밤 시간(예: 01~06시), 지숙이 게시는 정해진 시각에.
- 크롬 창은 각자 1개 프로필만. 남는 탭은 닫기.
- 저장: 내장 512GB는 프로그램용, 영상·결과물은 외장 SSD(구매 권장). 여유 50GB 미만이면 정리 후 시작.

**밖에서 지시하는 법**
- 리야: 휴대폰 리야 채팅 → 맥미니(자동 연결됨).
- 지숙이: 지숙이(Codex) 쪽 원격 방법으로. 안 되면 노트북에서 맥 **화면 공유**로 접속.

**모바일 지시**: 리야 = 휴대폰 Claude 앱(이 채팅) → 맥미니 `claude remote-control` / 지숙이 = 휴대폰 ChatGPT 앱 → 맥미니 **Codex 앱**("Set up Codex mobile" QR 연결, 같은 계정, 맥 깨어 있어야 함).
**규칙 파일(11-28 설치)**: `~/work/CLAUDE.md`(리야), `~/jisuk/AGENTS.md`(지숙이), 주고받기 `~/shared/넘김/{지숙이에게,리야에게}/`, 결과물 `~/shared/결과물/`.

**규칙**: 리야는 지숙이 폴더·브라우저·자동화를 읽기만 한다(수정·실행 금지). 계정 로그인은 사용자 직접.

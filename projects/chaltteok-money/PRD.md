# 찰떡 돈궁합 기획서 v0.1

> 두 사람의 생일로 보는 **연애 × 돈** 궁합. 토스 미니앱(앱인토스)으로 출시한다.
> 작성: 리야 · 2026-11-22 · 상태: 초안 (사용자 검토 전)

## 1. 한 줄 요약
"우리 커플, 데이트 비용은 누가 내야 맞을까?" 두 사람이 각자 생일을 넣으면 **돈 성향 캐릭터**와 **커플 돈궁합**이 병맛 카드로 나온다.

## 2. 왜 이 앱인가
| 근거 | 내용 |
|---|---|
| 토스 사용자 = 돈에 관심 많은 사람 | 금융 앱 안에서 열리는 운세라 "돈" 주제가 자연스럽다 |
| 기존 운세 앱의 빈틈 | 포스텔러·점신의 궁합은 연애·성격 위주. **커플의 돈 습관**을 다루는 곳은 드물다 |
| 궁합은 혼자 못 본다 | 상대에게 링크를 보내야 결과가 완성된다 → 사용자가 사용자를 데려온다 |
| 이미 만든 자산 | 「찰떡사주」 테스트판의 일주 계산(4,848일 검증), 오행 캐릭터, 병맛 톤을 재사용 |

## 3. 대상
- 토스 미니앱 규정상 **19세 이상**.
- 주 타깃: 20~30대 연애 중·썸 타는 사람, 신혼부부.

## 4. 사주 근거와 "돈 성향" 5유형
태어난 날의 천간(일간) 오행에서 착안한 **재미용 돈 성향**이다. 명리학의 정식 재물 분석(재성·식상 등)이 아니므로 화면에 "재미로 보는 성향"이라고 표시한다.

| 일간 오행 | 돈 성향 이름 | 특징 |
|---|---|---|
| 목 (나무) | 씨앗 심는 성장러 | 미래에 투자. 자기계발·배움에 돈을 아끼지 않음 |
| 화 (불) | 기분파 불꽃 소비러 | 경험·이벤트·선물에 화끈하게 씀 |
| 토 (흙) | 든든한 곳간지기 | 안정 최우선. 적금·비상금 필수 |
| 금 (쇠) | 칼정산 가계부 장인 | 가성비 계산, 더치페이는 원 단위까지 |
| 수 (물) | 흐름 타는 정보왕 | 할인·포인트·재테크 정보 수집, 상황 따라 유연 |

## 5. 커플 돈궁합 결과 구성
- **돈궁합 점수**: 찰떡사주 점수 규칙(천간합, 오행 상생·상극, 일지 육합·충·삼합, 띠)을 그대로 쓴다. 범위 52~99점.
- **커플 돈 유형** (오행 짝 15가지): 예) 화×토 「쓰는 손 막는 손 커플」, 금×금 「영수증 대조 커플」, 목×수 「같이 크는 적금 커플」
- **데이트 비용 추천**: 더치페이 / 데이트 통장 / 번갈아 쏘기 / 비율 정산 중 유형별 추천
- **돈싸움 주의보**와 **화해 비법**
- **같이 모으기 미션**: 예) "한 달 커피값 절반을 데이트 통장에"
- 근거 보기: 일주·오행·띠와 점수 계산 이유

## 6. 첫 버전 기능 (사업자 없이 출시)
1. **내 정보 입력**: 별명, 양력 생일 (태어난 시간은 v1에서 받지 않음)
2. **내 돈 성향 카드**
3. **상대 초대 링크**: `Share.createLink`로 `intoss://` 링크를 만든다. 링크에는 생일이 아니라 **계산된 코드(일간·일지·띠 번호와 별명)만** 담아 상대에게 내 생일이 노출되지 않게 한다
4. **상대가 링크로 들어와 자기 생일 입력 → 커플 돈궁합 결과**
5. **공유**: 결과 문구 보내기(`Share.sendMessage`), 카드 이미지 저장(`File.saveBase64`)
6. **기기 저장**: 내 별명·코드는 `Storage`(기기 안)에만 저장. 서버 없음

## 7. 다음 버전 (사업자 등록 후)
- 광고: 결과 화면 하단 배너(`TossAds`), 상세 보기 전 전면 광고
- 유료: **990원 상세 리포트** (인앱 결제 `IAP`) — 1년 커플 돈 달력(지출 주의 달, 같이 모으기 좋은 달), 함께 모으기 플랜
- 알림: 기념일·월급날 미션 알림(동의 받은 경우)

## 8. 기술
- Vite + React + TypeScript
- `@apps-in-toss/web-framework` 3.10.0 (토스 웹뷰 SDK, 설정은 `defineConfig`)
- 사주 계산: 자체 엔진(일주 공식 + 입춘표). 출시 전 만세력 라이브러리와 1921~2039년 전 날짜 자동 대조 테스트
- 서버 없음, 개인정보 저장 없음

## 9. 심사·정책 대비
- 토스 콘솔에 **운세 서비스 심사 기준을 먼저 문의**한다 (공식 문서에 운세 전용 기준 없음)
- 금지 표현: "반드시 돈 번다", 투자·대출 권유처럼 보이는 문장. 금융 앱 안이라 특히 조심
- 고지 문구: "재미로 보는 결과이며 금융 조언이 아닙니다"
- 개인정보 처리방침 초안: 수집 항목(별명·생일은 기기 안에서만 계산), 저장·전송 없음

## 11. 성공 지표

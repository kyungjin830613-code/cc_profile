# 찰떡 떡집 키우기 기획서 (PRD)

- appName: `chaltteok-ricecake` / 앱 유형: **게임**(방치형 클리커)
- 앱 이름(10자 이내): 찰떡 떡집 키우기 (9자)
- 폴더: `projects/chaltteok-ricecake/app`, 로고: `assets/logo-1024.png`, `assets/logo-600.png`
- 작성: 리야, 2026-11-23

## 1. 왜 만드나

- 토스 미니앱에서 돈을 가장 많이 버는 장르가 **방치형 키우기 게임**이다(용사단 키우기 1.5개월 80만 명, 거지키우기 인기 1위, 돌돌디 월 매출 2.1억).
- 토스 노출 기준은 **재방문율**. 키우기 게임은 "자리 비운 동안 쌓인 보상"과 "출석"으로 매일 다시 오게 만든다.
- 우리 운세 앱 2개와 목적이 완전히 달라서 유사 앱 정책에 걸리지 않는다.

## 2. 타깃과 한 줄 소개

- 토스를 매일 여는 20~40대. 출퇴근길, 점심시간 1~3분 플레이.
- 한 줄 소개: "말랑한 떡을 톡톡 빚어 동네 떡집을 전국 떡 공장으로 키워요."

## 3. 핵심 재미(구현 완료)

| 요소 | 내용 |
|---|---|
| 떡 빚기 | 큰 떡을 누르면 떡이 만들어지고 바로 팔린다(+숫자가 튀어 오름) |
| 도우미 7단계 | 견습생 찰떡이 → 떡메 장인 → 방앗간 기계 → 떡집 2호점 → 떡 공장 → 전국 떡 택배 → 해외 수출. 1초마다 자동 판매, 살 때마다 가격 15%↑ |
| 황금 절구 | 한 번 누를 때 빚는 떡 증가 |
| 떡 도감 10종 | 가래떡 → 인절미 → 꿀떡 → 송편 → 백설기 → 무지개떡 → 찹쌀떡 → 약식 → 두텁떡 → 황금 떡. 누적 판매량으로 해금, 하나 열 때마다 전체 판매 +10% |
| 자리 비운 동안 | 앱을 닫아도 절반 속도로 최대 8시간 판매. 돌아오면 "어서 와요, 사장님!" |
| 출석 | 하루 1회, 연속 출석할수록 보상 증가(최대 7일치) |
| 자랑하기 | 토스 공유로 "우리 떡집은 ○○까지 만들어요" + 앱 링크 |

## 4. 등급과 안전

- **전체이용가 목표.** 폭력·선정성 없음, **확률형 아이템(뽑기) 없음**, 유료 결제 없음, 게임 속 재화는 현금 가치 없음.
- 저장은 기기 안(토스 Storage)만. 서버·개인정보 수집 없음.
- 화면 하단에 "전체이용가 · 확률형 아이템 없음" 표시(등급 결과 나오면 등급 표시로 교체).

## 5. 수익화 계획(출시 후)

1. 1단계: 무료 출시, 재방문율·플레이 시간 측정.
2. 2단계: **보상형 광고** 2곳(사업자 없이 시작 가능, 누적 예상수익 5천 원까지 유예)
   - "자리 비운 동안 번 떡 2배 받기"
   - "출석 보상 2배"
   - 원칙: 광고는 사용자가 선택할 때만, 버튼에 "광고 보고" 표시, 전면 광고 남발 금지.
3. 3단계: 이벤트 떡(설날 떡국떡, 추석 송편 시즌 한정)으로 시즌마다 재방문 유도.

## 6. 출시 전 필수 절차(게임이라 추가로 필요)

1. 홈택스 사업자등록 정정: 기존 업종(통신판매, 전자상거래 소매)에 **게임 소프트웨어 개발·공급 업종 추가**.
2. **게임제작업 등록**(정부24 또는 구청 문화체육과).
3. **게임 등급분류**: 게임물관리위원회 업체회원 가입 후 신청(전체이용가는 간소화 신청 가능) 또는 구글 플레이 자체등급을 콘솔에 입력.
4. 토스 콘솔: 앱 만들기(유형 **게임**, 한 번 고르면 못 바꿈) → 등급 정보 입력(플레이 화면 캡처 2장씩) → 번들 업로드 → 검수.
5. 토스 게임 미니앱은 **풀스크린 대응**이 심사 필수 → 등록 전에 `apps-in-toss.config.ts`의 게임용 화면 설정을 공식 문서로 확인하고 맞춘다.

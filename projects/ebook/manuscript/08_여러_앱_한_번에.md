# 8장. 여러 앱을 한 번에 굴리기 — 앱 열네 개와 휴대폰 원격 운영

> 초안 v0.1 (2026-11-25, 리야). [확인]은 출간 전 다시 확인할 곳, [캡처]는 화면을 넣을 곳, [채움]은 실제 숫자를 넣을 곳.

## 이 장에서 얻는 것

- 앱 하나가 아니라 **열 개 넘게** 동시에 만들고 관리하는 구조
- 공통 부품 한 번 고치면 **모든 앱에 반영**되는 폴더 구성
- 번들 11개를 **명령 한 번**으로 다시 만들고 올린 방법
- **밖에서 휴대폰으로 지시하면 집 PC의 AI가 콘솔까지 처리**하는 원격 운영
- 원격 운영에서 생긴 문제와 규칙
- 끝에 **운영 점검표**

---

## 8-1. 하루에 앱 열네 개가 굴러간 날

11월 24일 하루 동안 이런 일이 동시에 진행됐다.

- 앱 2개 출시(지갑궁합·신년운세)
- 앱 11개 화면을 TDS로 다시 만들고, 번들을 다시 빌드해 콘솔에 다시 올림
- 새 앱 1개(하루 영단어) 기획·개발·로고·콘솔 등록
- 출시한 앱의 홍보 글 준비(9장)

나는 그날 대부분 **밖에 있었다.** 휴대폰으로 지시하고, 결과를 보고받고, PC 앞에 앉았을 때 사람만 할 수 있는 버튼(약관 동의, 게시)을 눌렀다.

이게 가능했던 건 두 가지 덕분이다. **앱들이 같은 구조로 만들어져 있었고**, **AI가 PC를 대신 움직일 수 있게 연결해 두었기** 때문이다.

---

## 8-2. 같은 구조로 만든다

모든 앱이 같은 뼈대를 쓴다.

```
projects/
  _shared/tds-base.css      ← 모든 앱이 같이 쓰는 바탕(토스 색·여백·카드)
  앱이름/
    PRD.md                  ← 기획서
    assets/logo-600.png     ← 로고
    app/
      src/lib/계산.ts        ← 핵심 계산(앱마다 다름)
      src/lib/계산.test.ts   ← 정답표 테스트
      src/lib/toss.ts       ← 토스 저장·공유·링크(모든 앱 같은 모양)
      src/App.tsx           ← 화면(TDS)
```

**좋은 점**
- 바탕 색·여백을 고치면 `_shared` 한 곳만 고치면 된다.
- 토스 저장·공유 코드가 같아서, 한 앱에서 고친 방법을 다른 앱에 그대로 옮긴다.
- AI에게 "다른 앱과 같은 구조로 새 앱을 만들어"라고 하면 30분 안에 뼈대가 나온다.

## 8-3. 한꺼번에 다시 빌드하고 올리기

TDS로 바꾼 뒤 11개 앱의 번들을 다시 만들어야 했다. 하나씩 하면 반나절이다. AI에게 이렇게 시켰다.

```
아래 11개 앱 폴더마다 차례로:
1) 최신 코드 받기
2) 의존성 설치 → 테스트 → 토스용 빌드(.ait)
3) 만들어진 .ait를 업로드 폴더로 모으기
4) 앱마다 한 줄: 폴더 / appName / 테스트 통과 수 / 빌드 성공 여부 / .ait 이름
그다음 콘솔에서 앱마다 새 번들 업로드. 상세 정보·로고는 건드리지 말고,
서약 체크와 검토 요청 직전에서 멈춰.
```

결과 보고는 이랬다(일부) [캡처: 실제 보고 표].

| 폴더 | appName | 테스트 | 빌드 | 업로드 |
|---|---|---|---|---|
| gyeongjo-book | gyeongjo-memo | 13/13 | 성공 | 새로 올림 |
| nbbang | nbbang-jeongsan-gi | 8/8 | 성공 | 새로 올림 |
| utility-bill | urizip-gonggwagum | 12/12 | 성공 | 새로 올림 |
| focus-timer | jipjung-timer-kr | 9/9 | 성공 | 새로 올림 |
| … 11개 전부 | | 통과 | 성공 | 새로 올림 |

> **멈출 곳을 지시문에 박아 둔다.** "서약 체크와 검토 요청 직전에서 멈춰." 이 한 줄이 없으면 AI가 어디까지 갈지 모른다.

## 8-4. 휴대폰으로 PC를 움직이는 구조

```
[나: 휴대폰]  →  [클라우드 AI 채팅: 작업본부]  →  [집 PC의 AI 코딩 도구]  →  [크롬·콘솔·파일]
     ↑                                                                    │
     └──────────────── 결과 보고(짧게) ←──────────────────────────────────┘
```

- **클라우드 AI(작업본부)**: 내 말을 받아 할 일을 정리하고, PC에 보낼 지시문을 쓰고, 결과를 확인해 짧게 보고한다. 원고·기획·조사처럼 PC가 필요 없는 일은 여기서 바로 한다.
- **PC의 AI**: 코드·빌드·브라우저 조작(콘솔 입력, 업로드, 캡처)을 한다.
- 연결: AI 코딩 도구의 원격 연결 기능으로 PC를 클라우드 채팅에 묶어 둔다. PC가 켜질 때 자동으로 연결되게 해 두었다 [확인: 도구별 기능명·설정 방법].

**하루 흐름 예**
- 08:30(출근길) "N빵 정산기 만들어 줘" → 클라우드가 기획서·코드·테스트·로고까지.
- 12:10(점심) "만든 앱들 콘솔에 올려" → PC가 등록·업로드, 검토 요청 직전 멈춤.
- 19:00(PC 앞) "PC 앞에 앉았어" → PC가 약관·서약 화면을 순서대로 띄움 → 나는 체크만.
- 19:18 출시 완료 보고.

## 8-5. 원격 운영에서 생긴 문제와 규칙

| 문제 | 무슨 일이 있었나 | 정한 규칙 |
|---|---|---|
| 승인 범위가 애매함 | PC의 AI가 "공개·출시는 본인 확인이 필요하다"며 멈춤. 매번 PC 채팅으로 가서 승인해야 했다 | **상시 승인 문장**을 미리 정한다: 앱 만들기·등록·검수 제출·출시까지 맡긴다. 단 로그인·본인인증·결제·대량 삭제는 항상 사람 |
| 말이 바뀌어 전달됨 | 클라우드가 요약해서 넘기면 뉘앙스가 바뀜 | PC에 보낼 때 **내 말을 원문 그대로 인용** |
| 사용 한도 | PC 쪽 AI가 5시간 사용 한도에 걸려 30분 넘게 멈춤 | 큰 작업은 한도 초기화 시각을 보고 나눈다. 멈추면 클라우드가 대신할 수 있는 일(원고·조사)을 먼저 |
| 보고를 그대로 믿음 | "다 됐습니다"였지만 화면을 보면 고칠 곳이 있었음 | 보고에 **캡처·숫자(테스트 통과 수, 버전, 시각)**를 꼭 넣게 한다 |
| 공개 글 게시 | 홍보 글은 내 이름으로 공개된다 | 게시 직전에서 멈추고, **게시 버튼은 내가** 누른다(9장) |
| 개인정보 | 화면 캡처에 이름·이메일·사업자번호가 찍힘 | 캡처는 저장 전 가리기. 개인정보는 외부 서비스에 보내지 않기 |

**상시 승인 문장 예(PC 쪽 AI 지침에 넣는다)**

```
클라우드 작업본부가 내 말을 원문으로 인용해 전달한 지시는 내 지시로 본다.
앱 만들기·등록·검수 제출·출시·영상 업로드/공개 포함.
로그인·본인인증, 결제, 대량 삭제는 예외로 계속 내가 직접 한다.
```

## 8-6. 한 장짜리 상태판

앱이 열 개를 넘으면 머릿속으로 관리가 안 된다. 앱마다 한 줄씩 상태판을 둔다.

| 앱 | appName | 단계 | 사람이 할 일 | 메모 |
|---|---|---|---|---|
| 찰떡 지갑궁합 | chaltteok-wallet | 출시됨 | - | 다음 업데이트 때 TDS |
| 경조사비 장부 | gyeongjo-memo | 검토 요청 직전 | 휴대폰 테스트·서약 | 새 번들 |
| 하루 영단어 | haru-eng-word | 등록 중 | - | |
| 13월의 월급 | bonus13 | 보류 | - | CARNIVAL |
| 찰떡 떡집 키우기 | chaltteok-ricecake | 준비 | 게임제작업·등급분류 | 게임 |

AI에게 "상태판 갱신해"라고 하면 콘솔을 보고 고쳐 준다. **'사람이 할 일' 칸만 모아 보면** PC 앞에 앉았을 때 할 일이 바로 나온다.

## 8장 정리

- 모든 앱을 **같은 구조**로: 공통 바탕 + 같은 토스 연결 코드 + 앱별 계산·화면.
- 반복 작업은 **목록 + 한 번의 지시문**으로, 멈출 곳을 꼭 적는다.
- 휴대폰 → 클라우드 작업본부 → PC의 AI로 연결하면 밖에서도 앱이 굴러간다.
- 상시 승인 범위, 원문 인용, 캡처·숫자 보고, 사람만 하는 버튼을 규칙으로 정한다.

### 운영 점검표

- [ ] 모든 앱이 같은 폴더 구조와 공통 바탕을 쓴다
- [ ] 반복 작업 지시문에 '멈출 곳'이 적혀 있다
- [ ] PC가 켜지면 원격 연결이 자동으로 된다
- [ ] PC 쪽 AI 지침에 상시 승인 문장과 예외(로그인·인증·결제·삭제)가 있다
- [ ] 지시할 때 내 말을 원문으로 전달한다
- [ ] 보고에 캡처·숫자가 들어 있다
- [ ] 상태판이 있고 '사람이 할 일'만 모아 볼 수 있다
- [ ] 캡처의 개인정보를 가린다

다음 장은 출시 후, **사람을 데려오는 법**이다.

# 9장. 출시 후 홍보 — 토스가 써 준 글부터 7일 루틴까지

> 초안 v0.1 (2026-11-25, 리야). [확인]은 출간 전 다시 확인할 곳, [캡처]는 화면을 넣을 곳, [채움]은 실제 숫자를 넣을 곳.

## 이 장에서 얻는 것

- 출시 직후 콘솔에 뜨는 **'토스에게 홍보 소재 맡기기'** 사용법과 고쳐 쓰는 요령
- 유튜브 쇼츠·인스타그램·스레드·블로그 **채널별 홍보 키트**
- 앱마다 **언제 밀어야 하는지** 시기표
- 출시 후 **7일 홍보 루틴**(부록 E와 같음)
- 홍보할 때 지킬 것

---

## 9-1. 출시를 축하해요, 그다음 화면

지갑궁합이 출시되자 콘솔에 **"출시를 축하해요"** 화면과 함께 버튼 하나가 떴다. **"토스에게 홍보 소재 맡기기."** [캡처]

신청서인 줄 알았다. 눌러 보니 달랐다.

- 토스 AI가 **홍보 글 1개와 홍보 이미지 10장**을 만들어 준다.
- "스레드에서 확인하고 올리기" 버튼을 누르면 **스레드 글쓰기 창**이 글과 이미지가 채워진 채로 열린다.
- **무료**다. 글 '다시 만들기'는 하루 10번까지 [확인].
- 화면 안내: "AI가 만든 글이라 사실과 다른 내용이 있을 수 있어요", "올리기 전에 글과 이미지에 개인정보가 없는지 확인해 주세요."

---

## 9-2. 토스가 써 준 글, 그대로 올리지 않는다

AI가 쓴 글을 우리는 이렇게 고쳤다.

| 고친 점 | 이유 |
|---|---|
| "재미로 보는"을 넣음 | 운세·궁합류는 재미 요소임을 밝힌다(과장 방지) |
| "안심하셔도 돼요" 같은 단정 문장 삭제 | 보장처럼 읽히는 표현은 뺀다 |
| 군더더기 문장 삭제 | 스레드는 짧을수록 읽힌다 |
| 앱 링크 추가 | 검색하라는 말만으로는 덜 들어온다. 바로 열리는 링크를 붙인다 |
| 이미지 10장 중 3장만 | 시작 화면, 입력 화면, 결과 카드. 날짜 선택 창·오류 문구가 찍힌 7장은 뺌 |
| 이미지 개인정보 확인 | 테스트 별명("테스트", "상대")만 있는지 확인 |

**최종 글의 구조(따라 쓰기 좋다)**
1. 공감 질문 한 줄: "커플끼리 돈 문제로 어색해진 적, 저만 있는 건 아니죠?"
2. 만든 이유 한 줄
3. 무엇을 해 주는지 2줄(재미로 보는 ○○, ○○ 팁)
4. 안심 정보 1줄(데이터는 기기 안에서만)
5. 댓글 유도 질문 1~2줄
6. "토스에서 '앱 이름' 검색" + 링크

**공개 버튼은 사람이 누른다.** 내 이름(계정)으로 공개되는 글이라, AI는 게시 직전까지만 준비하고 멈췄다. 확인하고 직접 '게시'를 눌렀다. [채움: 48시간 반응 — 조회·좋아요·댓글]

## 9-3. 채널별 홍보 키트

앱 하나를 홍보할 때 만드는 묶음이다. AI에게 한 번에 시킨다.

| 채널 | 형식 | 요령 |
|---|---|---|
| **유튜브 쇼츠** | 15~30초 화면 녹화 + 자막 | 첫 2초에 문제 상황("회식비 누가 얼마?"), 마지막에 "토스에서 ○○ 검색" |
| **인스타그램** | 결과 카드 이미지 3장 또는 릴스 | 저장하고 싶은 결과 카드 중심 |
| **스레드** | 짧은 글 + 링크(9-2 구조) | 첫 줄을 질문으로 |
| **블로그** | 검색용 사용법 글 | 검색어 제목("전기요금 계산 방법 2026"), 사용 순서 캡처, 계산 근거 출처 |

```
「○○」 앱 홍보 키트를 만들어 줘.
1) 쇼츠 대본 1개(장면·자막·내레이션, 30초 이내)
2) 인스타 결과 카드 이미지 3장 문구
3) 스레드 글 3개(첫 줄 질문형, 마지막 줄 검색어+링크)
4) 블로그 초안 1개(검색어 제목, 사용 순서, 출처)
지킬 것: 토스 로고·"토스 공식" 표현 금지, 과장·보장 표현 금지,
운세·돈 관련은 "재미로 보는/참고용", 개인정보 없는 화면만.
```

## 9-4. 언제 밀까 — 앱별 시기표

같은 앱도 시기가 맞으면 효과가 몇 배다.

| 시기 | 밀 앱 |
|---|---|
| 11월 말~1월 | 신년운세, 새해 소원 등불, 나의 돈 습관 결산 |
| 명절·결혼 시즌 | 경조사비 장부 |
| 난방철·냉방철 | 우리집 공과금 계산 |
| 연말 모임·회식철 | N빵 정산기, 오늘 점심 룰렛 |
| 새학기·시험 기간 | 집중 타이머, 하루 영단어 |
| 이사철 | 평수 계산기 |
| 1년 내내 | 물 한 잔 습관, 무지출 도장판, 디데이, 지갑궁합 |

**원칙:** 토스는 **다시 오는 사람**이 많은 앱을 더 노출한다(1장). 그래서 처음엔 **매일 쓰는 습관형 앱**에 홍보를 몰고, 공유형 앱(테스트·궁합)은 새 사람을 데려오는 용도로 쓴다.

## 9-5. 출시 후 7일 루틴

| 날 | 할 일 |
|---|---|
| D+0 (출시일) | '토스에게 홍보 소재 맡기기' → 고쳐서 스레드 게시. 앱 안 공유 문구·링크 확인 |
| D+1 | 인스타 결과 카드 3장. 첫날 반응 확인 |
| D+2 | 쇼츠 1편 업로드 |
| D+3 | 블로그 사용법 글 1편 |
| D+4 | 스레드 2번째 글(사용 팁 or 만든 이야기) |
| D+5 | 댓글·문의에 답하기, 받은 질문으로 스레드 3번째 글 |
| D+6 | 48시간·1주 반응 정리(조회·좋아요·댓글, 앱 방문·재방문) |
| D+7 | 잘된 채널에 다음 주 홍보를 몰아준다. 반응 없는 채널은 형식을 바꾼다 |

## 9-6. 홍보할 때 지킬 것

- 토스 로고·"토스 공식" 같은 표현을 쓰지 않는다. "토스 미니앱 ○○"라고 쓴다.
- "무조건", "보장", "최고" 같은 표현을 쓰지 않는다.
- 운세·돈 관련은 "재미로 보는", "참고용"을 붙인다. 투자·금융 조언처럼 쓰지 않는다.
- 사실(요금표·세율 등)은 출처를 확인한다.
- 캡처에 개인정보가 없게. 실존 인물 얼굴을 만들어 넣지 않는다.
- 유료 홍보(광고·포인트)는 재방문이 확인된 앱에만, 숫자를 보고 결정한다.

---

## 9장 정리

- 출시 직후 '토스에게 홍보 소재 맡기기'로 무료 홍보 글과 이미지를 받는다. **그대로 올리지 말고 고친다.**
- 채널별 키트를 한 번에 만들고, 시기표에 맞춰 민다.
- 7일 루틴으로 반응을 보고 잘된 채널에 몰아준다.
- 공개 게시 버튼은 사람이 누른다.

### 홍보 점검표

- [ ] 토스 홍보 소재 글을 고쳤다(재미 표시·단정 삭제·링크)
- [ ] 이미지 개인정보를 확인했다
- [ ] 키트 4종(쇼츠·인스타·스레드·블로그)을 만들었다
- [ ] 시기표에서 이 앱의 시기를 확인했다
- [ ] 7일 루틴 일정을 달력에 넣었다
- [ ] 48시간·1주 반응을 기록했다

# 6장. 콘솔 등록에서 막히는 것 전부 — 이름 중복 9번과 입력칸 오류 모음

> v0.2 (2026-11-25, 사실 확인 반영).

## 이 장에서 얻는 것

- 콘솔 등록 화면의 **입력칸별 규칙**을 한 표로
- 이름 때문에 막힌 **9번**(appName 중복 7 + 앱 이름 2)과 한 번에 통과하는 이름 짓는 법
- **입력 오류 모음**(증상 → 원인 → 고친 값)
- 상세 정보를 한 번에 채우는 **AI 지시문**
- 끝에 **등록 전 입력값 점검표**(부록 B와 같음)

---

## 6-1. 앱 이름 하나 정하는 데 아홉 번

「경조사비 장부」를 등록할 때였다. 앱의 고유 주소 이름(appName)에 `gyeongjo-book`을 넣었다. **"이미 사용 중인 이름"**. `gyeongjo-ledger`도 이미 있었다. 세 번째 `gyeongjo-memo`에서 통과했다.

다른 앱도 같았다. 「무지출 도장판」은 두 번, 「N빵 정산기」도 두 번 막혔다. 하루 동안 appName 중복으로 일곱 번, 앱 이름이 토스 서비스명과 같아서 두 번, 모두 아홉 번을 되돌아갔다.

게다가 이름이 바뀌면 일이 하나 더 생긴다. **앱 코드 안의 appName도 같이 바꾸고 다시 빌드**해야 한다. 콘솔과 코드가 다르면 앱이 제대로 연결되지 않는다.

이 장은 그 아홉 번을 여러분이 겪지 않게 하려고 쓴다.

---

## 6-2. 이름이 세 가지다

헷갈리기 쉬운 세 이름부터 정리한다.

| 이름 | 어디에 보이나 | 규칙(우리가 겪은 것) |
|---|---|---|
| **앱 이름(한글)** | 토스 앱 안 사용자에게 | **10자 이내**(입력칸 0/10). "토스 서비스명과 동일한 이름은 쓸 수 없어요" |
| **영문 이름** | 영어 표기가 필요한 곳 | 공백 빼고 15자 이내, 특수문자는 `:` `·` `?`만(하이픈 불가), 각 단어 첫 글자는 대문자 또는 숫자 |
| **appName** | 앱의 고유 주소(intoss://appName) | 영문 소문자·숫자·하이픈, **토스 전체에서 하나뿐이어야 함**(남이 쓰면 못 씀) |

> appName은 "내 워크스페이스 안에서"가 아니라 **토스 전체에서** 겹치면 안 된다. 그래서 흔한 영어 단어 조합은 대부분 누가 이미 쓰고 있다.

## 6-3. appName 중복 기록

| 앱 | 시도(막힘) | 통과 |
|---|---|---|
| 경조사비 장부 | gyeongjo-book ✕, gyeongjo-ledger ✕ | **gyeongjo-memo** |
| 나의 돈 습관 결산 | money-habit ✕ | **money-habit-test** |
| 무지출 도장판 | no-spend-challenge ✕, nospend-stamp ✕ | **mujichul-dojangpan** |
| N빵 정산기 | nbbang-calc ✕, nbbang-split ✕ | **nbbang-jeongsan-gi** |
| 무지출 도장판 | 앱 이름 "무지출 챌린지" ✕ | **무지출 도장판** |
| 평수 바로 계산 | 앱 이름 "평수 계산기" ✕ | **평수 바로 계산** |

(위 2건은 appName이 아니라 **한글 앱 이름**이 토스 서비스명과 같아서 막혔다. 처음 고른 appName으로 바로 통과한 앱은 10개였다. "비슷한 이름의 앱이 N개 있어요"라는 경고는 막지는 않는다.)

**보이는 패턴**
- `영어 일반명사 + 영어 일반명사`(money-habit, nbbang-calc)는 거의 다 선점돼 있다.
- **한글 발음을 로마자로 쓴 이름**(mujichul-dojangpan, nbbang-jeongsan-gi)은 한 번에 통과했다.
- 뒤에 `-kr`, `-test`, `-today`처럼 구분어를 붙이면 통과율이 높았다(dday-countdown-kr, lunch-roulette-today).

**한 번에 통과하는 이름 짓기 3원칙**
1. 한글 앱 이름을 **로마자 그대로**: 집중 타이머 → `jipjung-timer-kr`
2. 영어로 쓰고 싶으면 **3단어 + 구분어**: `water-cup-habit`
3. 후보를 **3개 미리** 정해 두고, 첫 번째가 막히면 바로 다음 것

**이름이 바뀌었을 때 AI에게**

```
appName이 '○○○'로 바뀌었어.
- 설정 파일(apps-in-toss.config)과 코드 안 APP_NAME을 모두 '○○○'로 바꾸고
- 테스트 → 빌드 → .ait 다시 만들기
- 바뀐 곳 목록과 새 .ait 파일 이름을 보고해
```

## 6-4. 입력칸별 규칙 한눈에

콘솔 상세 정보는 두 단계다. **1단계 '기본 정보'**: 앱 번들, 출시 노트, 메모, 한국어 앱 이름(10자), 영어 앱 이름(15자), 부제(20자), 상세 설명, appName(나중에 수정 불가), 사용 연령, 고객 문의 이메일. **2단계 '카테고리 및 노출'**: 카테고리, 앱 로고, 다크 모드 로고, 미리보기·스크린샷, 검색 키워드, 주요 기능, 서약 체크. [그림 6-1, 6-2] 자주 막히는 칸만 표로 정리했다.

| 입력칸 | 규칙 | 우리 예(하루 영단어) |
|---|---|---|
| 앱 이름 | 짧게, 토스 서비스명 금지 | 하루 영단어 |
| 영문 이름 | 15자 이내, 하이픈 금지, 단어 첫 글자 대문자 | Daily Words |
| 부제(한 줄 소개) | 20자, 비속어·느낌표 불가 | 하루 5단어, 복습 퀴즈로 외우기 |
| 상세 설명 | 기능을 사실대로, 금융·건강 조언처럼 보이는 표현 주의 | 기능 목록 + "기록은 기기 안에만 저장돼요" |
| 주요 기능 | **최대 3개**, 앱 이름과 같으면 안 됨, 한국어 10자·영어 15자, 특수문자는 `:` `.`만, 이모지 불가 | 오늘의 단어 / 복습 퀴즈 / 오답 단어장 |
| 카테고리 | 앱 성격에 맞게 대분류 → 소분류 | 교육·학습 > 어학 |
| 로고 | 600×600 PNG 1장(다크 모드 로고는 선택) | 단어 카드 "Aa" |
| 번들 | 빌드한 `.ait` 파일 | haru-eng-word.ait |

## 6-5. 입력 오류 모음

| # | 증상(콘솔 문구) | 원인 | 고친 값 |
|---|---|---|---|
| 1 | "이미 사용 중인 이름" | appName이 토스 전체에서 중복 | 로마자·구분어로 새 이름(6-3) |
| 2 | 앱 이름 저장 안 됨(「무지출 챌린지」) | 토스 서비스 이름과 같음 | 「무지출 도장판」 |
| 3 | "앱 영문 이름은 띄어쓰기를 제외하고 15자 이내로 입력해 주세요." | No Spend Challenge(16자), N-Split Calculator(17자) | 짧은 단어로 |
| 3-2 | "특수문자는 :, ·, ? 만 사용할 수 있어요." | N-Split Calc의 하이픈 | 하이픈 빼기 |
| 3-3 | "각 단어의 첫 글자는 대문자 또는 숫자여야 해요." | One Cup of Water(of 소문자) | 모든 단어 첫 글자 대문자 |
| 4 | "앱 이름과 같을 수 없어요." | 주요 기능에 앱 이름(경조사비 장부)을 넣음 | 기능을 구체적 동작으로("오늘의 단어") |
| 5 | 주요 기능 '추가하기' 버튼이 사라짐(오류 문구 없음) | 최대 3개 | 3개로 묶기 |
| 6 | 앱이 토스에서 안 열리거나 연결이 이상함 | 콘솔 appName과 코드 appName이 다름 | 코드 쪽을 콘솔 이름으로 맞추고 다시 빌드 |
| 7 | 번들을 바꿨는데 '토스앱 테스트'가 바로 안 됨 | 새 번들을 처리하는 중 | 잠시 뒤 다시 열면 테스트 버튼이 켜짐 |

## 6-6. 상세 정보를 한 번에 채우는 지시문

```
이 앱의 콘솔 상세 정보를 PRD.md를 바탕으로 써 줘. 규칙:
- 앱 이름: 짧게, 토스 서비스 이름과 겹치지 않게
- 영문 이름: 공백 빼고 15자 이내, 특수문자는 : · ?만, 각 단어 첫 글자 대문자
- 한 줄 소개: 과장 없이 무엇을 하는 앱인지
- 상세 설명: 기능을 사실대로 목록으로, 마지막 줄에 데이터 저장 방식
- 주요 기능: 3개 이하, 앱 이름과 다른 구체적 동작, 한국어 10자·영어 15자
- 카테고리 후보 2개
- appName 후보 3개(로마자 또는 3단어+구분어)
각 칸의 글자 수도 같이 적어 줘.
```

AI가 쓴 글에서 **"최고", "무조건", "보장", "전문가 수준"** 같은 말은 지운다. 운세·돈 관련 앱은 "재미로 보는", "참고용"을 넣는다.

## 6장 정리

- 이름은 세 가지(앱 이름, 영문 이름, appName). appName은 **토스 전체에서 하나뿐**이고 나중에 바꿀 수 없다.
- 로마자 이름과 구분어로 짓고, 후보 3개를 미리 준비한다.
- 이름이 바뀌면 코드도 바꾸고 다시 빌드한다.
- 주요 기능은 3개 이하, 앱 이름과 달라야 한다.

### 등록 전 입력값 점검표

- [ ] 앱 이름이 토스 서비스 이름과 겹치지 않는다
- [ ] 영문 이름 공백 빼고 15자 이내, 특수문자 `:` `·` `?`만, 단어 첫 글자 대문자·숫자
- [ ] appName 후보 3개 준비(로마자 / 3단어+구분어)
- [ ] 콘솔 appName = 설정 파일 appName = 코드 APP_NAME
- [ ] 한 줄 소개·상세 설명에 과장 표현 없음
- [ ] 주요 기능 3개 이하, 앱 이름과 다름, 이모지 없음
- [ ] 카테고리 선택
- [ ] 로고 600×600, 번들 .ait 최신 버전

다음 장에서는 등록한 앱을 **검수에 넣고 출시하는 순서**를 따라간다.

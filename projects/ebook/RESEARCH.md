# 전자책 시장 조사 (2026-11-24)

조사: 리야. 수치는 출처를 붙였고, 출처끼리 다르면 "불일치"로 표시했다.

## 1. 시장 크기

| 항목 | 내용 | 확인 정도 |
|---|---|---|
| 전자출판 플랫폼 매출(2025) | 주요 12개사 매출 합계 약 1조 5,656억 원. **웹툰·웹소설 포함**이라 전자책만의 크기는 아님 | 대한출판문화협회 2025 출판시장 통계(2026-04) |
| 전자책 시장(2023) | 2014년 3,820억 → 2023년 1조 3,000억 원 이상, 연평균 15% 넘게 성장 | 국민일보 기사(한국출판인회의 조사 인용) |
| 블로그 수치 | 800억~850억 원 등 | **불일치**, 쓰지 않음 |

**해석:** 종이책은 줄고 전자책·오디오북·구독(밀리의서재 등)은 커지는 흐름. 다만 우리가 팔 **"노하우 전자책(PDF)"**은 서점 전자책과 다른 시장이다. 크몽·리틀리·와디즈 같은 재능·크리에이터 장터에서 팔리고, 공식 통계는 없다.

## 2. 노하우 전자책(크몽 등) 시장

- **잘 팔리는 주제:** 실무 노하우, 투자, 다이어트, 자기계발, **부업 방법** 같은 실용 콘텐츠(판매자 블로그). 크몽 전자책을 8개 대분류·60개 세부 주제로 나눈 분석 상품도 있을 만큼 주제가 세분화돼 있다.
- **가격대(불일치):** "9,900~29,000원대가 가장 많이 팔림"(블로그), "보통 2만 원 내외"(크몽 상품 페이지), "3만~5만 원 이상이 유리"(다른 글). 9,900원 → 29,000원으로 올렸더니 판매가 늘었다는 경험담도 있음(개인 사례).
- **크몽 등록 조건:**
  - 공식 가이드: 이미지·사진·여백이 분량의 **30% 이상이면 등록 불가**, 파일 1개 200MB 이하.
  - 최소 분량은 블로그마다 다름(A4 20쪽 이상 / 가로 30쪽·세로 20쪽 이상) → 등록 전 공식 가이드 재확인.
  - 반려 사유(블로그): 분량 부족, 독창성 부족, 과장·허위 표현, 본인 창작물이 아님.
- **수수료:** 크몽 판매자 서비스 이용료 구간제 16.4%(70만 원 이하)·9.4%·4.4% + 결제망 3.3% + 부가세(여러 자료 일치). 리틀리 1~5% + PG 별도(리틀리 공식).

## 3. 우리 1권 주제의 경쟁 상황 — 「AI와 둘이서 토스 미니앱 출시하기」

| 경쟁 | 내용 | 우리와의 차이 |
|---|---|---|
| 토스 공식 문서 | Claude Code·Cursor·Codex로 미니앱 만드는 튜토리얼(무료) | 개발 과정 중심. 정책 반려·검수·홍보·사업자 같은 **실전 시행착오는 적음** |
| 토스 웨비나 | Claude Code로 대화만으로 미니앱 만들기 라이브(무료, 종료) | 1개 앱 시연. 여러 앱 운영·출시 후 이야기는 없음 |
| 오프라인 하루 강의 | 앱인토스 수익화 하루 완성, 189,000원(얼리버드), 30석 | 비싸고 장소·시간 제약. 결과물은 QR 실행까지 |
| 크몽 제작 대행 | 미니앱 기획~출시 대행(프로토타입 10만 원, 정식 20만 원 표시) | 직접 하는 법을 알려주지 않음 |
| 크몽 전자책 | **(11-24 PC 정밀 조사로 정정)** 앱인토스 전자책이 이미 6권 넘게 있다: '50일 안에 토스 미니앱 50개'(15,000·리뷰1), '토스미니앱 20개로 월 50만원'(39,000·리뷰1), '코딩 1도 몰랐는데 토스에 앱 6개'(14,000·리뷰1), '토스 미니앱 6개 출시하고 5번 반려당한 기록 58p'(29,000·리뷰0) 등 | → 빈자리는 아니지만 **리뷰 0~3개, 1등이 없는 초기 시장** |

**결론:** 수요는 있고(유료 강의 189,000원, 제작 대행 수요, 토스가 직접 웨비나), 전용 전자책은 몇 권 나왔지만 리뷰가 거의 없는 초기 시장이다(`research/kmong_top10.md`). 우리 강점은 **"직접 10개 넘게 만들어 출시하고 홍보까지 한 실제 기록"**과 **반려·정책 사례**다. 토스 공식 문서가 무료라서, 개발 따라 하기만으로는 팔리지 않는다. **"무엇을 만들어야 통과하고, 출시 후 어떻게 사람을 모으나"**에 집중해야 한다.

## 4. 위험 요소

- 토스 정책·화면이 자주 바뀐다 → 책에 "2026년 11월 기준"을 적고, 바뀌면 구매자에게 무료 개정판을 준다(신뢰 포인트).
- 크몽 이미지 30% 제한 → 캡처 위주로 하면 반려된다. 글 70% 이상, 캡처는 꼭 필요한 곳만.
- 수익 과장 금지 → 실제 숫자(방문·재방문)만 쓴다. 아직 수익이 작으면 작다고 쓴다.
- 우리 앱 성과가 나오기 전에 내면 설득력이 약하다 → 출시 후 2~4주 지표를 넣고 낸다.

## 5. 수요 조사 — 어떤 전자책이 잘 팔리나 (2026-11-24 추가)

### 서점 전자책(교보·밀리의서재 등)
- 교보문고 2026 상반기 종합 베스트(온라인·오프라인·eBook 합산)에 경제경영서 『돈의 방정식』(8위), 『자본주의 시대에서 살아남기 위한 최소한의 경제 공부』(9위)가 들었다. 2025년 10월에도 경제경영서가 10위권 여러 자리를 차지(매일신문).
- 밀리의서재 2026년 1월: 라이프스타일 +36%, 외국어 +31%, 자기계발 +14%, 소설 +11%(전월 대비). **새해에는 '나를 바꾸는' 책 수요가 뛴다** → 우리 1월 출간 계획과 맞다.
- 밀리의서재 2026 상반기: 소설은 '소장', 경제·자기계발서는 밑줄 그으며 '학습'. → 실용서는 **따라 하며 배우는 구성**(체크리스트, 단계)이 맞다.
- 교보 eBook 단독 연간 순위·리디·예스24 2026 데이터는 아직 공개 자료 없음(연말 이후 재확인).

### 노하우 전자책(크몽)
- 판매 실적이 높은 상품은 **AI·부업·수익화** 주제에 몰려 있다. 예: 'AI 사업·수익화' 전자책 평점 4.8·리뷰 299개·617건 판매 표기, 'AI 부업 3종' 리뷰 35개·50건 판매 표기(판매자 자가 표기, 가격 표기에 코칭·묶음이 섞여 있어 전자책 단가로 보기 어려움).
- 같은 AI 주제라도 저가·후기 없는 상품은 판매 1건 수준 → **주제보다 '신뢰 근거(실적·후기)'가 판매를 가른다.**
- 상위 상품 공통 신뢰 장치(상품 페이지 관찰): 수상·강사 경력, 판매 건수·리뷰 수 노출, 결과 인증.
- 정밀 분석(상위 10권 상세페이지) 완료 → `research/kmong_top10.md`. 목차·장 수 정밀 분석 진행 중 → `research/toc_analysis.md`.

### 수요 결론
1. 돈 버는 법·AI 활용·부업은 서점과 크몽 양쪽에서 수요가 크다. 우리 주제(AI로 토스 미니앱 만들어 수익화)는 이 교집합에 있다.
2. 경쟁 상품은 'AI 부업' 일반론이 많고, 앱인토스 전자책은 몇 권 있지만 **리뷰 0~3개로 아직 1등이 없다.** '반려 기록'을 내세운 책도 있어서, 우리는 범위(가입→정책→TDS→검수→출시→홍보→지표)와 실무 자료(판정표·오류 모음·지시문)로 차별화한다.
3. 팔리는 상품은 신뢰 근거가 있다 → 우리 앱 출시 화면, 반려·승인 메일, 실제 지표를 책과 상세페이지에 넣는다(개인정보 가림).
4. 1월 출간 + 따라 하기 체크리스트 구성이 수요 흐름과 맞다.

## 6. 팔리는 부업 전자책의 구조 (크몽 부업·수익화 인기 상위 10개, 2026-11-24)

| 항목 | 관찰 |
|---|---|
| 분량 | 5p~629p로 편차가 크다. 강의·코칭이 붙은 고가 상품은 5~41p로 짧고, 전자책 자체가 주력인 상품은 184~629p로 두껍다(중간값 약 200p). 장 수가 확인된 것: 42챕터(521p), 본편 44+심화 13챕터 |
| 목차 흐름 | 왜 이걸 해야 하나(문제 제기) → 기초 개념 → 세팅 → 단계별 실행 → 노출·수익화 → 최신 정보·부록. 블로그 권장 틀도 비슷하다: 문제·배경 → 실패 기록 → 전환점 → 단계별 방법(체크리스트) → 결과·데이터 |
| 신뢰 장치 | 제목의 구체적 숫자+기간, 수익·지급 캡처, 리뷰 수, 두꺼운 분량, '개정판·최신본' 표시 |
| 부록 | 계산기·장부·실무표·템플릿·VOD·1:1 코칭을 묶어 3단 패키지로 판다 |
| 상세페이지 | 숫자 후킹 → 저자 증명 → 공감 → 구성품 → 긴급성(선착순·인상 예고) → 환불 규정 |
| 표지 | 4:3, 검정·노랑·빨강 고대비, 큰 숫자, 저자 사진·캐릭터 |

**독자에게 주는 메시지(시사점):** 독자는 "정보"보다 **"이 사람이 실제로 해냈다는 증거"와 "그대로 따라 할 수 있는 순서"**를 산다. 분량은 '빠짐없이 다 들어 있다'는 신호로 쓰인다. 개정판 표시는 '정보가 낡지 않았다'는 약속이다.

**우리 책에 적용(PLAN.md 반영):** ① 제목에 실제 숫자(등록 수·출시 수·걸린 시간) ② 장마다 '얻는 것 → 우리 실패담 → 단계별 방법 → 정리 → 체크리스트' 같은 틀 ③ 판정표·오류 모음·지시문 템플릿을 부록으로 ④ 개정판 약속 ⑤ 3단 패키지.

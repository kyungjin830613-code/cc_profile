# 전자책 1권 출간·판매·홍보 실행 계획

작성: 리야, 2026-11-25. 사용자 지시 원문: "다시 한번 얘기하지만 전자책 허접하게 쓸 거 아니지? 제대로 써서 제대로 홍보해가지고 뭐, 어디 사이트, 크몽 아니면은 뭐 어디에다 판매를 할 건지 그것도 구체적으로 다 계획을 세워야 돼."

책: 「AI와 둘이서 토스 미니앱 출시하기」(가제, 제목은 출간 시점 실제 숫자로 확정). 목차·조사는 `PLAN.md`, `RESEARCH.md`, `research/`.

출간 전에 아래를 **전부** 통과해야 판매 등록한다.

## 2. 어디서 파나 — 판매처와 역할

| 판매처 | 역할 | 언제 | 수수료(확인) | 준비할 것 |
|---|---|---|---|---|
| **크몽** (메인) | 검색 유입·리뷰·신뢰. 앱인토스 전자책 14권+ 모두 리뷰 0~3개 → 리뷰 선점이 목표 | 12/08 전후 오픈 | 판매자 서비스 이용료 구간제 16.4%(70만 원 이하)·9.4%·4.4% + 결제망 3.3% + 부가세(여러 자료 일치, 등록 화면에서 최종 확인) | 전문가 전환, 프로필, **본인·계좌 인증(사용자 직접)**, 표지(4:3), 미리보기 이미지 5장 이상, PDF, 서비스 설명. 심사 평일 2~3일(블로그 기준) |
| **리틀리** (직판) | 우리 채널(스레드·유튜브·블로그)에서 오는 사람을 받는 판매 페이지. 수수료가 낮아 직판 이익이 큼 | 크몽과 같은 날 | 1~5%(누적 결제액 따라 낮아짐) + PG·부가세 별도, 매주 금요일 정산(리틀리 공식) | 가입·정산 계좌(사용자 직접), 판매 블록에 PDF 등록, 무료 맛보기 블록 |
| **와디즈** (2차) | 개정판·묶음(전자책+템플릿+영상) 펀딩 | 판매 1개월 뒤 반응 보고 결정 | 출시 전 공식 요금 확인 | 펀딩 페이지, 리워드 구성 |
| **교보 퍼플 등 서점** (3차) | 일반 서점 노출 | 개정판(3월 이후) 검토 | 자료마다 달라 공식 확인 후 | ISBN·서점용 편집본 |

**왜 크몽 + 리틀리 둘 다?**
- 크몽: 사려는 사람이 이미 모여 있는 곳. 리뷰가 쌓이면 검색 상위로 간다. 대신 수수료가 높다.
- 리틀리: 우리가 데려온 사람에게 수수료 적게 파는 곳. 스레드 프로필·쇼츠 설명란 링크는 모두 리틀리로.
- 가격은 두 곳 같게(구매자 혼란 방지).

## 3. 상품 구성과 가격

| 상품 | 구성 | 가격 | 근거 |
|---|---|---|---|
| **기본** | 전자책 PDF(본문+부록 7종) + 무료 개정판 | **29,000원** (오픈 2주 얼리버드 19,900원) | 앱인토스 전자책 14,000~49,000원대, 크몽 일반 전자책 2~3만 원대 |
| **실전 패키지** | 기본 + 지시문 원본 파일 모음 + 콘솔 입력값·제출 체크리스트 엑셀 + 정책 판정표 엑셀 | **59,000원** | 크몽 상위서 패키지 4.5만~19.9만 원 |
| **1:1 점검** (선택, 사용자 결정) | 실전 패키지 + 내 앱 기획 1개 정책·검수 점검(서면 피드백) | **149,000원** | 상위서 3단 패키지 구조. 사용자가 시간을 낼 수 있을 때만 연다 |

- 가격은 오픈 직전 크몽 경쟁작 가격을 다시 보고 최종 확정.
- 환불: 크몽 규정 + 리틀리 디지털 상품 규정을 상세페이지에 명시.

## 4. 일정 — 빠른 출간 (11-25 사용자 지시로 앞당김)

사용자 지시 원문: "무슨 출시를 뭐 1월까지 늦출 필요는 없어. 최대한 빨리 완성되는 대로, 지금 뭐 그 다음 전자책도 계속 계획하고 있으니까, 먼저, 다 완성되고 표지 만들고, 어, 출간할 수 있을 정도의 퀄리티로, 만들어줘."

원칙: **품질 기준 10개(1절)는 그대로**, 기다리는 시간만 없앤다. 장이 끝나는 대로 다음 단계로 바로 넘어간다.

| 목표일 | 할 일 | 누가 |
|---|---|---|
| 11/25 ~ 11/28 | 6~9장 + 프롤로그 + 부록 7종 집필(하루 1~2장) | 리야 |
| 11/25 ~ 11/28 | 증거 캡처 모으기(개인정보 가림) | PC |
| 11/28 ~ 11/30 | 10장(결과·회고): 출시 앱 첫 1주 실제 지표로 정직하게(작은 숫자도 그대로) + "개정판에서 4주 지표 추가" 약속 | 리야 |
| 11/29 ~ 12/02 | 베타 독자 2~3명 빠른 따라 하기(2~7장, 3일) → 수정. 섭외가 어려우면 리야가 비개발자 관점 체크리스트로 대신 점검 후 오픈, 첫 구매자 피드백으로 개정 | 사용자 섭외, 리야 정리 |
| 11/30 ~ 12/02 | 교정 2회, [확인] 0개, 용어 통일 | 리야 |
| 11/30 ~ 12/02 | **표지 3안** + 내지 PDF + 미리보기 이미지 5~8장 + 상세페이지 | 리야, 사용자 선택 |
| 12/02 ~ 12/03 | 크몽 전문가 전환·본인/계좌 인증, 리틀리 가입·계좌 | **사용자 직접**(인증) |
| 12/03 | 크몽 등록 제출(심사 평일 2~3일) | 리야(PC) |
| **12/08(월) 전후** | **크몽·리틀리 동시 오픈** | 리야(PC) |
| 오픈 ~ +2주 | 얼리버드 19,900원 → 정가 29,000원 | 리야 |
| 오픈 +4주 | 결과 보고, 4주 지표 넣은 개정판 배포 | 리야 |

> 원고·디자인이 더 빨리 끝나면 그날 바로 제출한다. 다음 전자책(2권)은 1권 제출 직후 기획에 들어간다.

## 5. 홍보 계획 (지금부터 오픈 후 4주까지)

### 5-1. 오픈 전 (지금 ~ 오픈 전날): 관심 모으기

| 채널 | 무엇을 | 빈도·시작 |
|---|---|---|

| **유튜브 쇼츠** (@ilsangbihwa 말고 별도 채널 여부는 사용자 결정) | 5편 시리즈: ① 이틀 만에 앱 2개 출시 ② 다 만들고 보류된 앱 ③ 이름 중복 9번 ④ 11개를 다시 만든 이유(TDS) ⑤ 토스가 써 준 홍보 글 | 11/29부터 주 2편 |

| **무료 맛보기** | 3장(정책 사전 검사) 요약본 PDF 10쪽 → 리틀리 무료 배포, 받은 사람에게 오픈 알림(동의한 경우만) | 12/01 |

### 5-2. 오픈 주 (오픈일 ~ +6일): 런치 위크

- 1일차: 스레드·블로그·쇼츠 설명란에 오픈 공지 + 얼리버드 마감일.
- 2~6일차: 매일 책 속 "막힘 사례" 하나씩 스레드에 공개(책의 일부 맛보기).
- 베타 독자 3명에게 솔직한 후기 요청(크몽 리뷰는 **실제 구매자만**, 리뷰 조작·대가성 리뷰 금지).
- 우리 토스 미니앱 안 공유 문구·링크는 **토스 정책 확인 후에만** 활용.

### 5-3. 오픈 후 (+1주 ~ +4주): 꾸준히

- 스레드 주 3회: 독자 질문에 답하는 글(=책의 FAQ 확장).
- 블로그 주 1회, 쇼츠 주 1편.
- 리뷰 들어오면 상세페이지 상단 갱신.
- 토스 정책 바뀌면 개정판 공지 → "업데이트되는 책" 신뢰 쌓기.

### 홍보 지킬 것
- `projects/TOSS_PROMO_GUIDE.md`의 규칙 그대로: 토스 로고·"토스 공식" 금지, 과장 금지, 개인정보 가림, 공개 게시 전 사용자 확인.

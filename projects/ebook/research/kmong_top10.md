- 조사일: 2026-11-24 (반짝이, 로그인 없이 공개 화면만 열람)

- 판매 수는 상세페이지에 공개되지 않는다. 상단의 하트 숫자는 **찜 수**다.

### 상세페이지 구성 순서 (10개 공통 틀)
크몽 화면 탭 순서는 고정이다: **책소개(제목·평점·미리보기·리뷰 요약) → 목차 → 서비스 설명 → 가격 정보(패키지 표) → 자주 묻는 질문 → 전문가 정보 → 리뷰**.
판매자가 직접 꾸미는 '서비스 설명'은 대체로 이 순서다.
1. 첫 줄에서 숫자 성과나 강한 문제 제기("리뷰부터 보세요", "이 숫자에서 시작합니다")
2. 저자 증명(수익 캡처, 기록, 경력)
3. 공감(왜 다들 실패하는가, 허황된 강의 비판)
4. 구성품·혜택 목록(부록, 계산기, 템플릿, VOD, 1:1)
5. 가격 인상·선착순 같은 긴급성
6. 환불 규정, 파일 형식(PDF)

## 4. 요약

### 상위 10개 공통점
1. 제목은 **구체적인 숫자 성과와 기간**이다(5일간 100만원, 16일 만에 100만, 4개월 5400만원, 월 200).
2. 가격은 **3단 패키지**(전자책 → VOD·부록 → 1:1 코칭)나 고가 단일 상품이다. 전자책 하나만 파는 경우는 드물다.
3. 신뢰는 **수익·지급 내역 캡처, 리뷰 수, 대량 분량(400~629p), 개정판 표시**로 만든다.
4. 표지는 **4:3 썸네일, 검정·노랑·빨강 고대비, 큰 숫자, 저자 사진이나 캐릭터** 구성이다.
5. 서비스 설명은 **숫자 후킹 → 저자 증명 → 공감 → 구성품 나열 → 가격 인상·선착순 → 환불 규정** 순서다.

### 가격대
- 부업·수익화 상위권의 기본 패키지는 **4.5만~19.9만 원**이다. 고가 단일 상품은 65만~319만 원이다.
- 상위 패키지(1:1 포함)는 39만~330만 원이다.
- 앱인토스·바이브코딩 전자책은 현재 **1만~4만 원대**이고 리뷰가 적다.
- 교보 IT 종이책 기반 eBook은 2만~3만 원대다.

### 우리 책에 적용할 점
1. **사실 숫자로 제목 짓기:** "비개발자가 하루에 토스 미니앱 14개 등록, 2개 출시한 실제 기록"처럼 콘솔에 남은 숫자만 쓴다. 수익은 실제로 생기기 전에는 쓰지 않는다.
2. **경쟁 전자책에 없는 실무 자료를 증명으로:**
   - 정책 사전 검사 판정표(연말정산 계산기 반려 등)
   - appName 중복으로 막힌 9건과 대처법
   - 영문 이름·기능 이름 입력 규칙 오류 모음
   - 약관·서약·출시 순서
   - TDS 전환
   이걸 캡처와 함께 넣으면 리뷰 0~3개인 기존 책들과 차이가 난다.
3. **3단 구성:**
   - ① 전자책(2.9만~3.9만)
   - ② +프롬프트·템플릿 코드·체크리스트(7.9만 안팎)
   - ③ +등록 대행·1:1 점검(상위 가격)
   - 판매처: 크몽(검색 유입) + 리틀리(스레드 유입) 둘 다 쓴다.

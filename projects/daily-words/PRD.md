# 하루 영단어 (appName `haru-eng-word`)

## 한 줄 소개
하루 5단어를 외우고, 잊을 때쯤 다시 나오는 복습 퀴즈로 영단어를 내 것으로 만드는 습관 앱.

## 왜 다시 오나
- 매일 새 단어 5개(날짜로 고정) + 복습할 단어가 매일 생긴다.
- 연속 공부 일수, 배운 단어·완전히 외운 단어 수가 쌓인다.
- 정책 사전 검사: '상식·단어 퀴즈' APPROVED(2026-11-23). 점수 경쟁·보상이 없는 학습 도구로 만든다(게임 분류 피하기).

## 기능
1. 단계 선택: 기초 / 중급 / 토익·실무 (각 60단어, 총 180단어)
2. 오늘의 단어 5개: 카드로 보기(품사, 뜻 보기, 발음 듣기)
3. 퀴즈: 4지선다(같은 품사 보기). 새 단어 + 오늘 복습할 단어
4. 복습 간격: 맞히면 1·3·7·14·30일 뒤, 틀리면 다음 날. 다섯 번 맞히면 '완전히 외운 단어'
5. 자주 틀린 단어 목록
6. 공유: 연속 공부 일수·배운 단어 수

## 화면
TDS(@toss/tds-mobile) 사용: SegmentedControl, ListHeader/ListRow, Button, ProgressBar, Paragraph.

## 데이터
기기 안에만 저장(토스 Storage, 토스 밖은 localStorage). 서버 전송 없음.

## 확인
- vitest 8개: 단어장 180개·중복 없음, 오늘 단어 고정, 복습 간격, 오답 처리, 연속 일수, 보기 4개, 복원.
- 브라우저: 외우기 → 퀴즈 → 결과 → 처음 화면 흐름, 오류 없음.
- 발음은 브라우저 음성 합성(지원 안 되면 버튼 숨김).
